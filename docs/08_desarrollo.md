# 08. Desarrollo

## Principios

- El producto precede al SQL.
- El modelo precede a la API.
- La API es consecuencia del modelo.
- El Excel oficial constituye el mecanismo de validación, no la especificación funcional.
- LocalAPI integra información sin duplicar responsabilidades.

## Flujo

1. Identificar necesidad.
2. Definir el producto.
3. Delimitar alcance.
4. Identificar fuentes de verdad.
5. Registrar hallazgos.
6. Documentar decisiones.
7. Diseñar modelo lógico.
8. Construir diccionario.
9. Implementar vista SQL.
10. Validar contra publicación oficial.
11. Publicar endpoint.
12. Desarrollar viewer.
