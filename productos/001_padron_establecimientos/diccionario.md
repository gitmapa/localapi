# Diccionario de datos

Agregar una columna 'Estado' con los valores:

| Estado | Significado |
|---|---|
| MVP | Se publica en el Producto 001 |
| Futuro | Documentado para productos posteriores |
| Excluido | Pertenece a otro producto |

El resto del diccionario conserva la estructura existente y cada atributo debe clasificarse según este estado.
