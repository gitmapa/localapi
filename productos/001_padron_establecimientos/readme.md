# Producto 001 - Padrón de Establecimientos Educativos

## Alcance

Incluye:

- Identidad educativa.
- Identidad edilicia.
- Localización.
- Información territorial.
- Geografía.

No incluye:

- Oferta educativa.
- Variables que cuentan.
- Dependencia funcional.
- Indicadores.
- Estadísticas.

El Producto 001 representa exclusivamente el padrón integrado de establecimientos.
