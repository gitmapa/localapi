# Changelog

Todos los cambios relevantes del proyecto LocalAPI se documentan en este archivo.

El formato utilizado se inspira en *Keep a Changelog* y el versionado sigue, cuando resulte aplicable, los principios de *Semantic Versioning*.

---

## [0.1.0] - 2026-06

### Agregado

- Creación del proyecto LocalAPI.
- Integración de PostgreSQL mediante `postgres_fdw`.
- Publicación automática de vistas mediante PostgREST.
- Generación automática de documentación OpenAPI.
- Integración con Swagger UI.
- Primera implementación utilizando datos del dominio RANIE.
- Documentación metodológica completa.
- Definición de la arquitectura de integración.
- Definición de la metodología de desarrollo de MAPA.

### Estado

Primer MVP funcional del laboratorio.
